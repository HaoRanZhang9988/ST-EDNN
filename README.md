# ST-EDNN
ST-EDNN — bidirectional spatiotemporal cross-modulation for accurate, efficient, and stable time-dependent PDE solving.

A spatiotemporal-encoding dynamic neural network for time-dependent PDEs. Bidirectional spatial-temporal cross-modulation with grouped partial modulation adapts to spatial heterogeneity and temporal evolution, while an eigendecomposition-accelerated Levenberg–Marquardt solver cuts overhead — delivering lower error, faster convergence, and long-horizon stability.
